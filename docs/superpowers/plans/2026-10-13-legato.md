# Legato Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Android-only local music player (gapless, lossless, playlists, queue, ReplayGain) in Before/Tsundoku's black-and-ivory look.

**Architecture:** Single `app` module, manual DI, MVVM with StateFlow. `PlaybackService` (Media3 `MediaSessionService`) owns ExoPlayer; the UI drives it only through a `MediaController`, so the queue lives in the player. Library comes from MediaStore; Room holds playlists and play stats.

**Tech Stack:** Kotlin, Jetpack Compose + Material3, Media3 (ExoPlayer, session), MediaStore, Room, Coil, Robolectric + JUnit for JVM tests.

**Spec:** `docs/superpowers/specs/2026-10-13-legato-design.md`

## Global Constraints

- Android only. No network, no accounts, no catalog. Local files via MediaStore.
- AGP 9.1.x, Kotlin 2.4.x, compileSdk/targetSdk 37, minSdk 24, Gradle 9.3.1, JVM target 11.
- `applicationId` and namespace `com.phuuun.legato`. Single module `:app`. No DI framework, no multi-module.
- Theme tokens copied from Before/Tsundoku, not shared: dark background `#000000`, surface `#0D0D0E`, elevated `#161618`, outline `#26262A`, outlineVariant `#3F3F46`, text `#FFFFFF` / `#A1A1AA` / `#71717A`; light ivory `#FFFDF4`, ink `#2A2924`, outline `#DDD9C8`. `surfaceContainer*` set explicitly. Follows system dark/light, no dynamic colour. Artwork is the only colour.
- `play_stats` is written in v1 (play count incremented on track completion).
- Tracks are referenced by MediaStore id; a deleted file is skipped on load, never a crash.
- Permissions: `READ_MEDIA_AUDIO` (+ `POST_NOTIFICATIONS` on 13+), requested with a one-screen explainer.
- Build env (from Before's notes): `export JAVA_HOME=/home/phuuun/Projects/Tools/android-studio/jbr`; adb at `/home/phuuun/Projects/Tools/Android/Sdk/platform-tools/adb`; phone is `943f15`. Never run `connectedDebugAndroidTest` (it uninstalls the app); use `adb install -r`.
- Out of scope for v1: EQ, smart shuffle, lyrics, sleep timer, widgets, tag editing, Android Auto.

## Review Focus

1. Tracks with no artist/album/title tags: show "Unknown artist" / "Unknown album" / file name, never blank or crash (Task 2).
2. Two albums with the same name by different artists must stay separate: group by MediaStore album id, not name (Task 2).
3. Empty library and denied permission show an empty state, not a blank screen (Task 3).
4. A playlist referencing a deleted file loads without it and does not crash playback (Task 6).
5. ReplayGain missing, malformed, or positive gain must never push volume above 1.0 or produce NaN (Task 8).
