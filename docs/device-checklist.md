# Device checklist

Walk this on the phone (`943f15`) before calling a release done. Mark each line with the date and result.

- [ ] **Gapless:** two consecutive tracks from a live album play with no pause between them.
- [ ] **Lock screen:** play/pause, next and previous work from the lock screen and the notification.
- [ ] **Bluetooth:** play/pause, next and previous work from headphones or the car.
- [ ] **Kill while playing:** swipe Legato away in recents while a song plays; playback keeps going and the notification still controls it.
- [ ] **Permission:** deny music access, see the explainer, then grant it and see the library.
- [ ] **Deleted file:** delete a file that is in the queue and in a playlist; the queue skips it with a short message, the playlist hides it, nothing crashes.
- [ ] **Long and non-Latin titles:** a very long title and a non-Latin title (e.g. Japanese) ellipsize cleanly in the mini player and rows.
- [ ] **FLAC:** a FLAC file plays.
- [ ] **ReplayGain:** a track with ReplayGain tags plays quieter by its gain; an untagged track plays at full volume; nothing clips.
